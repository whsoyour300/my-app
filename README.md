# 생산·품질 질문 앱

한국어로 묻으면 AI가 DuckDB SQL을 쓰고, 브라우저에서 실행해 결과 · 산출 근거 · 원인 한 단계를 보여 줍니다.

## 쓰기 전에

1. 이 앱은 데이터를 브라우저 안에서 읽는다. 올린 파일은 서버에 저장되지 않는다.
2. AI에는 질문 · 테이블 설명 · 집계 결과(최대 50행)만 간다. 원본 행은 가지 않는다.
3. AI가 쓴 SQL은 실행 전에 읽어 보고, 결과 숫자 하나는 직접 검산한다.
4. 올린 파일의 «읽은 행 수»와 «올라간 행 수»가 다르면(✕) 그 결과를 믿지 않는다.
5. 파일 이름이 같으면 나중에 올린 파일이 앞의 것을 대신한다.
6. 시험은 투입 5~6일 뒤에 하므로, 월말에 투입한 로트의 시험 결과는 다음 달 파일에서 채워진다.

## 내 PC에서 실행

```
cp .env.example .env      # GEMINI_API_KEY 를 .env 에 적는다 (.env 는 커밋하지 않는다)
python tools/serve.py     # http://127.0.0.1:8780
```

## Vercel 배포

- 환경 변수: `GEMINI_API_KEY`(필수), `GEMINI_MODEL`(선택, 기본 `gemini-3.5-flash-lite`)
- `public/`은 정적 파일, `api/*.py`는 Python 함수로 배포된다. 외부 패키지는 필요 없다.
- `.vercelignore`가 `.env` · `tools/` · `다음달/`을 뺀다. 기본 데이터는 `public/data/`에 있고 가상 데이터라 함께 배포한다.
